# Auftrag 11.1: Gesamtexport aller Rezepte als ZIP

> Erstellt 2026-11-17 vom Master · Roadmap: `ROADMAP.md` Punkt 11.1 · Basis: `main@48d9b3b` · Aufwand: M · Modell: Opus

## Ziel
Ein Admin lädt in der Verwaltung den gesamten Rezeptbestand als ZIP herunter: Rezepte mit Tags, alle Bilder (Fotos und Vorlagen) und ein Manifest. Das ZIP ist so aufgebaut, dass 11.2 es ohne Informationsverlust wieder einspielen kann. Es dient außerdem als Sicherung vor dem PostgreSQL-Upgrade (W.21). Ein Import gehört nicht zu diesem Auftrag.

## Auftrag
1. **Format** (Version 1), im Plan nachtragen:
   - `manifest.json`: `format: "my-cookbook-export"`, `version: 1`, `exported_at` (UTC, ISO 8601), `app_commit`, Anzahl Rezepte und Bilder, Liste fehlender Bilddateien.
   - `recipes/<id>.json` je Rezept: `id`, `recipe_name`, `data`, `tags`, `created_at`, `updated_at`, `created_by`, `updated_by`, `images: [{id, kind, sort_order, filename, mime_type, file}]`. `file` ist der Pfad im ZIP. Es ist JSON statt YAML, siehe Entscheidungen.
   - `images/<image_id>.<ext>`: das Original, falls vorhanden, sonst die optimierte WebP-Fassung. Thumbnails werden nicht exportiert, 11.2 erzeugt sie beim Import neu.
2. **Backend:** `GET /v1/admin/export` (nur `admin`), Antwort `application/zip` mit `Content-Disposition`, Dateiname `my-cookbook-export-<JJJJ-MM-TT>.zip`.
   - Das ZIP mit `zipfile` aus der Standardbibliothek in eine temporäre Datei schreiben und per `FileResponse` ausliefern. Die Datei wird danach per Background-Task gelöscht. Bilder ohne Neukompression schreiben (`ZIP_STORED`), JSON komprimiert (`ZIP_DEFLATED`).
   - Ein Rezept, dessen Bilddatei fehlt, wird trotzdem exportiert. Das fehlende Bild steht im Manifest und im Log, der Export bricht nicht ab.
   - Den Code in einen Service legen, z. B. `app/services/export.py`; die Route bleibt schlank.
3. **`app_commit`:** Das Backend-Image bekommt `COMMIT_HASH` als `ARG`/`ENV`. Die CI übergibt es schon, `docker-compose.build.yml` ebenfalls nachziehen. Fehlt der Wert, steht `"dev"` im Manifest.
4. **Frontend:** Button „Gesamtexport (ZIP)“ in `AdminRecipes.vue`, nur für `admin` wie die übrigen Admin-Aktionen. Laden mit Auth-Header als Blob und als Datei anbieten, mit Lade- und Fehlerzustand. Timeout großzügig, mindestens 120 s, siehe Fallstricke.
5. **Tests:**
   - DB-Test: zwei Rezepte, eines mit Foto und Vorlage. Das ZIP enthält Manifest, beide Rezept-Dateien und beide Bilder; Inhalte, `kind` und `sort_order` stimmen; ein fehlendes Bild steht im Manifest.
   - Nicht-`admin` erhält 403.
   - Vitest für den Button: API gemockt, Download ausgelöst, Fehler angezeigt.
6. **Doku:** README-Abschnitt „Backup“ um den Gesamtexport ergänzen. Er ersetzt `backup.sh` nicht. Der Plan nennt das Format und streicht die erledigten offenen Punkte.

## Entscheidungen, die ich treffe
- keine. Der Master hat entschieden:
  - **JSON statt YAML im ZIP:** Das Backend hat seit W.18 keine YAML-Bibliothek. JSON kommt ohne neue Abhängigkeit aus und lässt sich verlustfrei wieder einlesen.
  - **Thumbnails werden nicht exportiert.**
  - **Temporäre Datei statt echtem Streaming:** Der Bestand ist klein, und `zipfile` braucht zum Schreiben eine Datei mit `seek`.

## Fallstricke
- **Original und WebP-Fassung:** Wurde eine WebP-Datei hochgeladen, sind Original und optimierte Fassung dieselbe Datei `originals/<id>.webp`. Die Endung des Originals ergibt sich aus `mime_type`. Ist das Original nicht auffindbar, die WebP-Fassung exportieren. In der DB steht nur der Pfad der WebP-Fassung.
- **Pfade im ZIP** nur aus IDs bilden, nie aus `filename` oder `recipe_name`. Das verhindert Path-Traversal und Namenskonflikte.
- **Zeitgrenzen:** nginx hat für `/api/` die Standard-Timeouts von 60 s, und der äußere Reverse-Proxy kann eigene setzen. Messen: Exportdauer bei realistischer Größe, z. B. 200 Rezepte mit je zwei Bildern, synthetisch erzeugt. Liegt sie deutlich unter 60 s, ist keine Änderung an nginx nötig; sonst `location` für `/api/v1/admin/export` mit längerem Timeout und das im Bericht nennen.
- **Temporäre Datei** nicht in `UPLOAD_DIR` ablegen, sonst findet das Admin-Aufräumen sie als verwaiste Datei. Stattdessen `tempfile` verwenden. Liegt `/tmp` im Container zu knapp, ein Verzeichnis außerhalb der Uploads wählen und das begründen.
- **Parallel läuft W.33** und ändert `AdminRecipes.vue` (YAML-Import). Die eigene Änderung dort klein halten, Konflikte beim Merge löst der Master.
- **DB-Tests lokal** nur mit `postgres:16-alpine`. Attrappen für Dateisystemfunktionen plattformneutral bauen (Rule `backend-tooling.md`).
